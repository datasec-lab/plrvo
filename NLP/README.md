# PLRV-O Trainer

This is a reference implementation of **PLRV-O** for the NLP experiment.

This code is forked from the [`FastDP`](https://github.com/awslabs/fast-differential-privacy)

---

## Requirements

All dependencies are listed in [`text_classification/requirements.txt`](./examples/text_classification/requirements.txt) or [`table2text/requirements.txt`](./examples/table2text/requirements.txt). You can install them using:


```bash
pip install -r requirements.txt
```

---

## How to Use

To generate the data found in the paper, run commands step by step in demo.sh for classification or generation task, respectively.
