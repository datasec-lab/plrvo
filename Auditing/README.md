# PLRV-O Trainer

This is a reference implementation of **PLRV-O** for the auditing experiment.

This code is forked from the [`ClipBKD`](https://github.com/jagielski/auditing-dpsgd)

---

## Requirements

All dependencies are listed in [`requirements.txt`](./requirements.txt). You can install them using:


```bash
pip install -r requirements.txt
```

---

## How to Use

To generate the data found in the paper, run commands step by step in demo.sh for CV or NLP task, respectively.
